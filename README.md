# Bizim Gizli Bahçemiz — Dilek Söğüdü

İki kişiye özel, mobil ve masaüstü uyumlu romantik web uygulaması.

## Özellikler
- **2 Özel Hesaplı Giriş & Gizli Takip Paneli:** Yalnızca yönetici hesabının görebildiği giriş/çıkış zaman damgası, aktif çevrimiçi durumu ve oturum süresi takibi.
- **Karşılama Ritüeli & Dilek Söğüdü:** Giriş anında dilek modalı, Söğüt dallarına asılan ipek kurdeleler, gerçekleşen dileklerde konfeti patlaması ve parlayan altın yıldız dönüşümü, Dilek Defteri arşivi.
- **Gizli Mektup Kutusu:** Söğüt ağacının altında iki kişiye özel okundu bilgili mektup alanı.
- **Çiçek Kataloğu & Saksılarım:** 18 farklı çiçek türü; tohumdan filize, tomurcuktan tam çiçeğe 3-5 günlük büyüme simülasyonu, günlük sulama, güneş konumu seçimi, kişisel notlar ve **Flora AI Sulama Danışmanı**.

## Çalıştırma
```bash
npm install
npm run dev
```
- Geliştirme ortamında arayüz `http://localhost:5173`, API sunucusu `http://localhost:3001` adresinde çalışır.
- Üretim derlemesi için:
```bash
npm run build
npm start
```
